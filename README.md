# Pizza-Store-0.1
🍕 Pizza E-Commerce Website

A modern and responsive pizza e-commerce website where customers can explore delicious pizzas, browse the menu, view prices, and enjoy a smooth online food-shopping experience.

🌟 Features

- 🏠 Home Page — Attractive landing page with featured pizzas.
- 🍕 Pizza Menu — Browse different pizza varieties and categories.
- 🔍 Search Functionality — Find your favorite pizzas easily.
- 🛒 Shopping Cart — Add or remove pizzas and manage quantities.
- 💰 Price Calculation — Calculate the total cost of selected items.
- 📱 Responsive Design — Works on desktop, tablet, and mobile devices.
- 📞 Contact Page — Contact information and customer support.
- 🎨 Modern UI — Clean layout with an appealing pizza-themed design.

🛠️ Technologies Used

- HTML5 — Website structure
- CSS3 — Styling, animations, and responsive layouts
- JavaScript — Interactive functionality and cart management
